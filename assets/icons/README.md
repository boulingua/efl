# Lucide icons

Drop the local SVGs from <https://lucide.dev> into this folder. Suggested set
covering the five-step template + recurring topical icons:

- `brain-circuit.svg` — Activate
- `book-open.svg` — Input
- `dumbbell.svg` — Practise
- `mic.svg` — Produce
- `compass.svg` — Reflect
- `clipboard-pen.svg` — Klassenarbeit
- `graduation-cap.svg` — Abitur
- `globe.svg`, `flag.svg` — Cultural anchors
- Topical: `utensils`, `home`, `school`, `paw-print`, `cloud-sun`,
  `book`, `theater`, `leaf`, `factory`, `cpu`, `heart-handshake`,
  `scale`, `vote`, `newspaper`, `mountain`, `tent`, `lightbulb`.

Use them in slide and article markup via the `.icon-circle` CSS
helper:

```html
<span class="icon-circle">
  <svg>...inline SVG...</svg>
</span>
```
