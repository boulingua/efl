The twelve Units of Grade 10 (E) across the school
year. Each Unit covers roughly three teaching weeks.

| Unit | Title | Skills focus | Exam type |
|------|-------|--------------|-----------|
| 1 | [Identity in a Global World](/track-e/kl10/units/unit01-identity-in-a-global-world/) | reading, writing, intercultural | class test ("Klassenarbeit") |
| 2 | [The World of Work](/track-e/kl10/units/unit02-the-world-of-work/) | reading, speaking, intercultural | class test ("Klassenarbeit") |
| 3 | [Digital Lives](/track-e/kl10/units/unit03-digital-lives/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 4 | [Australia and New Zealand](/track-e/kl10/units/unit04-australia-and-new-zealand/) | reading, listening, intercultural | class test ("Klassenarbeit") |
| 5 | [Media and Democracy](/track-e/kl10/units/unit05-media-and-democracy/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 6 | [Contemporary Short Fiction](/track-e/kl10/units/unit06-contemporary-short-fiction/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 7 | [Mediation: A German Feature Article](/track-e/kl10/units/unit07-mediation-feature-article/) | mediation, writing, language_awareness | class test ("Klassenarbeit") |
| 8 | [Science and Society](/track-e/kl10/units/unit08-science-and-society/) | reading, writing, intercultural | class test ("Klassenarbeit") |
| 9 | [Youth Protest Movements](/track-e/kl10/units/unit09-youth-protest-movements/) | reading, speaking, intercultural | class test ("Klassenarbeit") |
| 10 | [A Short Novel](/track-e/kl10/units/unit10-a-short-novel/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 11 | [Public Speaking and Debate](/track-e/kl10/units/unit11-public-speaking-and-debate/) | speaking, listening, language_awareness | class test ("Klassenarbeit") |
| 12 | [Year Review: Toward Oberstufe](/track-e/kl10/units/unit12-year-review-toward-oberstufe/) | writing, speaking, language_awareness | class test ("Klassenarbeit") |
