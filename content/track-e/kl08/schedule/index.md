The twelve Units of Grade 8 (E) across the school
year. Each Unit covers roughly three teaching weeks.

| Unit | Title | Skills focus | Exam type |
|------|-------|--------------|-----------|
| 1 | [Identities](units/unit01-identities/) | reading, writing, intercultural | class test ("Klassenarbeit") |

| 3 | [Fairness at School](units/unit03-fairness-at-school/) | speaking, writing, language_awareness | class test ("Klassenarbeit") |
| 4 | [Ireland: Stories from the Island](units/unit04-ireland-stories/) | reading, writing, intercultural | class test ("Klassenarbeit") |
| 5 | [Digital Friendships](units/unit05-digital-friendships/) | listening, writing, language_awareness | class test ("Klassenarbeit") |
| 6 | [Writing an Opinion](units/unit06-opinion-writing/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 7 | [Mediation: A Teen Magazine](units/unit07-teen-magazine-mediation/) | mediation, writing, language_awareness | class test ("Klassenarbeit") |
| 8 | [Music and Belonging](units/unit08-music-and-belonging/) | listening, speaking, intercultural | class test ("Klassenarbeit") |
| 9 | [Rural and Urban Lives](units/unit09-rural-and-urban/) | reading, writing, intercultural | class test ("Klassenarbeit") |
| 10 | [A Novella in Class](units/unit10-a-novella-in-class/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
