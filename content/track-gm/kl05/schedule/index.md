The twelve Units of Grade 5 (G+M) across the school
year. Each Unit covers roughly three teaching weeks.

| Unit | Title | Skills focus | Exam type |
|------|-------|--------------|-----------|
| 1 | [Hello World](units/unit01-hello-world/) | speaking, listening, language_awareness | class test ("Klassenarbeit") |
| 2 | [My Family](units/unit02-my-family/) | speaking, writing, language_awareness | class test ("Klassenarbeit") |
| 3 | [Home and My Room](units/unit03-home-and-room/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 4 | [A School Day](units/unit04-school-day/) | listening, speaking, language_awareness | class test ("Klassenarbeit") |
| 5 | [Food and Drinks](units/unit05-food-and-drinks/) | reading, speaking, language_awareness | class test ("Klassenarbeit") |
| 6 | [Animals and Pets](units/unit06-animals-and-pets/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 7 | [Weather and Seasons](units/unit07-weather-and-seasons/) | listening, writing, language_awareness | class test ("Klassenarbeit") |
| 8 | [Hobbies and Sports](units/unit08-hobbies-and-sports/) | speaking, listening, language_awareness | class test ("Klassenarbeit") |
| 9 | [Birthday and Friends](units/unit09-birthday-and-friends/) | speaking, writing, language_awareness | class test ("Klassenarbeit") |
| 10 | [A Day in London](units/unit10-a-day-in-london/) | reading, listening, intercultural | class test ("Klassenarbeit") |
| 11 | [Clothes and Colours](units/unit11-clothes-and-colours/) | speaking, writing, language_awareness | class test ("Klassenarbeit") |
| 12 | [Review and Show](units/unit12-review-and-show/) | speaking, writing, language_awareness | class test ("Klassenarbeit") |
