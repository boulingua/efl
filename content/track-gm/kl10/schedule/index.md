The twelve Units of Grade 10 (G+M) across the school
year. Each Unit covers roughly three teaching weeks.

| Unit | Title | Skills focus | Exam type |
|------|-------|--------------|-----------|
| 1 | [Transition After Grade 10](units/unit01-transition-after-grade-10/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 2 | [The World of Work](units/unit02-the-world-of-work/) | reading, speaking, intercultural | class test ("Klassenarbeit") |
| 3 | [Digital Lives at Work](units/unit03-digital-lives-at-work/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 4 | [Australia Now](units/unit04-australia-now/) | reading, listening, intercultural | class test ("Klassenarbeit") |
| 5 | [Media and Truth](units/unit05-media-and-truth/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 6 | [Contemporary Short Fiction](units/unit06-contemporary-short-fiction/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
| 7 | [Mediation: A Workplace Text](units/unit07-mediation-workplace-text/) | mediation, writing, language_awareness | class test ("Klassenarbeit") |
| 8 | [Civic English: Rights and Voices](units/unit08-civic-english/) | reading, speaking, language_awareness | class test ("Klassenarbeit") |
| 9 | [Youth and the Future](units/unit09-youth-and-the-future/) | reading, writing, intercultural | class test ("Klassenarbeit") |
| 10 | [Project and Presentation](units/unit10-project-and-presentation/) | speaking, writing, language_awareness | class test ("Klassenarbeit") |
| 11 | [A Short Novel](units/unit11-a-short-novel/) | reading, writing, language_awareness | class test ("Klassenarbeit") |
