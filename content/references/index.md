on this site. Per-Unit "Further reading / listening" callouts point
to specific authentic resources for that topic; the references below
are the framework, not the topic-by-topic reading.

## Citing this course

If you use these materials in teaching, research, or further
publication, please cite the site rather than individual pages so
that revisions remain traceable.

**APA (7th ed.):**

> Le Boulanger, S. (2026). *EFL: A two-track English curriculum
> for comprehensive school (Grades 5–13)* \[Open educational
> resource\]. <https://boulingua.github.io/efl/>

**BibTeX:**

``` bibtex
@misc{leboulanger2026efl,
  author       = {Le Boulanger, S.},
  title        = {{EFL}: A Two-Track English Curriculum for
                  Comprehensive School (Grades 5--13)},
  year         = {2026},
  howpublished = {\url{https://boulingua.github.io/efl/}},
  note         = {Open educational resource.
                  Code: MIT; teaching content: CC-BY-SA 4.0}
}
```

When citing a single Unit, add the course track, grade, and Unit
title (e.g. *Track E, Grade 6, Unit 3 — In the City*) to the
reference so readers can locate the specific material.
