The rubric framework used across all Units. Per-Unit rubrics
specialise these for the specific writing task.

## Klassenarbeit (Kl. 5–10) Notenschlüssel

Standard BW grading scale (Notenschlüssel). Adjust by ±2 points per Niveau if local
practice differs; this is the default.

| Erreichte Punkte (% der Höchstpunktzahl) | Note |
|------------------------------------------|------|
| 92–100 % | 1 (sehr gut) |
| 81–91 %  | 2 (gut) |
| 67–80 %  | 3 (befriedigend) |
| 50–66 %  | 4 (ausreichend) |
| 30–49 %  | 5 (mangelhaft) |
| 0–29 %   | 6 (ungenügend) |

## Klassenarbeit task weighting

Default split per Klassenarbeit (3–5 tasks). Per-Unit Klassenarbeiten
may shift weights toward the Unit's skill focus by up to ±5 % per
task.

| Aufgabentyp | Anteil (Default) |
|-------------|-----------------|
| Listening / Reading comprehension | 30 % |
| Use of English (vocabulary, grammar in context) | 20 % |
| Mediation (from Kl. 7) | 15 % |
| Writing (productive) | 30 % |
| Other (matching, ordering, etc.) | 5 % |

## Niveau-Differenzierung

| Niveau | Aufgabentypen | Schreibumfang | Stützmaterial |
|--------|---------------|---------------|---------------|
| G | dominant geschlossen, kurze produktive Aufgabe | 60–100 Wörter | Bildimpulse, Wortgeländer, Modellsätze |
| M | Mischung geschlossen / halb-offen, eine Mediation, kurze Schreibaufgabe | 100–160 Wörter | Wortlisten, Strukturhilfen |
| E | weniger Stützen, offen, Mediation + längere Schreibaufgabe | 150–250 Wörter | Aufgabenstellung, Kontext |

## Abitur (Kl. 11–13) — schriftliche Prüfung

Default grading grid (Bewertungsraster) for Track E Kl. 11–13 schriftliche school-leaving examination ("Abitur")-
Aufgaben. Inhalt and Sprache are weighted differently in basic course ("Basisfach")
and advanced course ("Leistungsfach").

| Teil | BE (Default) | Schwerpunkt |
|------|--------------|-------------|
| Part A — Comprehension | ca. 24 BE | inhaltsbezogenes Verstehen |
| Part B — Analysis | ca. 18 BE | Texterschließung, Sprache des Textes |
| Part C — Composition / Comment | ca. 18 BE | eigenständige Stellungnahme |
| Mediation oder Translation | ca. 30 BE | Sprachmittlung |
| **Summe** | **ca. 90 BE** | — |

### Inhalt / Sprache — Gewichtung

| Bereich | Basisfach | Leistungsfach |
|---------|-----------|---------------|
| Inhalt  | 50 %      | 40 %          |
| Sprache | 50 %      | 60 %          |

In der Sprache wird unterschieden zwischen *kommunikativer Textgestaltung*
(Aufbau, Kohärenz, Adressatenbezug) und *sprachlicher Korrektheit und
Variabilität* (Wortschatz, Grammatik, Idiomatik, Register).

## Abitur — Kommunikationsprüfung

Default split for the oral school-leaving examination ("Abitur") Komponente.

| Teil | Dauer | BE |
|------|-------|----|

## House style for productive writing

These conventions appear across every Unit's writing tasks so that
learners are not surprised when they see them in a class test ("Klassenarbeit") or
school-leaving examination ("Abitur"):

- **Capitalisation.** Only proper nouns and the start of sentences.
  Common nouns are not capitalised in English.
- **Quotation marks.** Use English-style "double" quotes for direct
  speech and 'single' for embedded quotes.
- **Tense.** Stay in one tense unless the task changes register.
  Default to past simple for narrative, present simple for
  description, present perfect for relevance-now.
- **Connectives.** Vary across simple (*and*, *but*, *so*) and
  complex (*although*, *therefore*, *however*) by year group ("Klassenstufe").
- **Word count.** Within ±10 % of the stated range. Going below is
  penalised; going far above is penalised.
